- **You can align a section first and propagate the alignment afterward.**
  Alignments > Propagate transform > Start propagation recording now picks up
  the last transform change you made on the current section, so an Align by
  correlation you have already checked can go straight to Propagate to start or
  Propagate to end without being done again. It only counts a change made on
  that section since your last edit elsewhere, and a change you undid or
  already recorded is left out.
