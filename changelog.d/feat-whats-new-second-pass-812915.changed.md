- **`Help > Turn off What's new pop-up` is now `Show What's new after each
  update`, ticked while the pop-up is on.** It reads the same way as the
  `Show this changelog window after each update?` box at the bottom of What's
  new, so the two always show the same tick. Your choice is kept.
- **What's new sets menu names like `Delete from sections...` in the same font
  as menu paths and shortcuts.** A path whose last item ends in "...", such as
  `File > Backup > Settings...`, keeps its dots, and a long command breaks
  after its `|` instead of starting the next line with a blank.
