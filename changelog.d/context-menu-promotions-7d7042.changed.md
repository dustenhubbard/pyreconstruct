- **"Reapply autoseg colors..." is one hop shallower on the object menus.** On
  the object list it sat inside `Object attributes >`, and in the field it sat
  three menus deep under `Object > Object attributes >`, even though for
  automatic-segmentation users it is a routine bulk pass over imported objects
  rather than an attribute edit. It is now a top-level row of the
  object-settings section on both surfaces, directly below the
  `Object attributes >` submenu it left, so anyone who learned the old home
  finds it beside that submenu instead of inside it. Nothing else moved, the
  label is unchanged, and the action keeps its internal name, so any stored
  keyboard shortcut still binds.
