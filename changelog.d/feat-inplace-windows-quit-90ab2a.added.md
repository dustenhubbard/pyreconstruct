- **PyReconstruct Dev on Windows can install an update when you quit, without
  the installer.** After Download & Install, the update dialog says the update
  installs when you quit, with a Restart Now button. At quit a small helper
  swaps in the new version and opens the series you had open. If the new
  version does not start, the helper puts the old one back. A release turns
  this on for Dev first. Until then, and on Stable, macOS and Linux, updates
  use the installer as before.
