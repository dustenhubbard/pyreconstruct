- **Backup Settings can give each series its own backup folder without typing
  `{series}`.** Under My Defaults in `File > Backup > Settings...`, pick a
  folder and check `Put each series' backups in a subfolder named by its series
  code`. Backups then go to a subfolder named by the series code, made when the
  folder exists. A default folder saved with `{series}` at the end opens as that
  folder with the box checked and backs up to the same place, and a folder
  picked without it stays as it was. The dialog is also shorter and scrolls on a
  small screen, with OK and Cancel always in view.
