- **Eight default shortcuts moved off reflex traps.** (Chords named for
  macOS; on Windows and Linux read Cmd as Ctrl and Option as Alt.) Palette
  increment leaves the zoom keys, now Cmd+] and Cmd+[. The z-trace list
  leaves the redo chord Cmd+Shift+Z, now Cmd+Option+Z. Restart leaves the
  refresh key Cmd+R, now Cmd+Option+R. Options moves to the standard
  preferences key, Cmd+comma. Paste attributes moves to the paste-special
  convention, Cmd+Shift+V. Hide-selected and merge-traces leave Cmd+H and
  Cmd+M, which macOS reserves for Hide and Minimize, now Shift+H and
  Shift+M. Every freed chord stays unbound, so an old habit does nothing
  rather than something surprising. Cmd+B still pastes attributes as a
  legacy alias until you bind that chord to something else; menus show only
  the new key. Everything remains remappable.
