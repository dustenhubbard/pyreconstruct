- **`File` ▸ `Save as...` follows the case rule of the folder you save into.**
  A Linux folder that ignores case (`chattr +F`) no longer lets `b.jser` take
  the place of a deleted `B.jser` still in the 3D scene, and a case-sensitive
  Windows folder no longer refuses `b.jser` while the 3D scene holds `B.jser`.
