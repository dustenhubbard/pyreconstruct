- **Auto-backup and the backup folder can be set once for every series.**
  `File` > `Backup` > `Settings...` has a new `My Defaults (all series)` group
  with a backup folder and an auto-backup switch. Type `{series}` in the folder
  and each series backs up to a folder named by its series code, made on the
  first backup. A series with no backup settings of its own uses the defaults,
  including a new series and a copy from another computer. A series that has
  its own folder or has auto-backup on keeps them, and `Use my defaults for
  this series` switches any series either way.
